This project is a simple Dictionary Management System built using a Red-Black Tree in Python to ensure efficient word insertion and lookup. Words are stored both in memory (using the balanced tree) and persistently in a text file (Dictionary.txt). The system offers an interactive console menu where users can add new words, search for existing ones, and track tree properties like size and height. Red-Black Tree balancing logic is implemented through rotations and color rules, maintaining optimal performance (O(log n)).
